## ADR-024 TDDB 配置入口与 `tddb` 段（Phase 0）
**决策**：
- TDDB 用单独一份配置 `examples/zro2_tddb.yaml`，材料、缺陷段、电极、势垒、层厚与
  `examples/single_run.yaml` 相同（`test_tddb_example_matches_leakage_reference_preset` 保证一致）。
  初始缺陷与生成的 O 空位共用这份缺陷段（§6.7）。
- 生成参数放在顶层 `tddb` 段，由 `io.py` 解析成 `TDDBConfig`（SI）；省略即纯漏电流仿真。
  **字段在用到它的 Phase 才加入**，每个字段加入时都有取值和消费它的代码。
- 场加速项 p₀·(2+k)/3·E 的 k 取介质静态 `kappa`，不另设配置项。
- 恒压应力取 `simulation.voltage_V` / `temperature_C`（ADR-033 确认不单列）。

## ADR-026 小盒子的系综个数与 Phase 0 验证结果（Phase 0）
**决策**：`ensemble.count = 30`。

**验证**：20×20 nm（M=128）与 50×50 nm（M=32）在 {2,3,4} V × {25,125} °C 六个工作点上均值之差都在
合成标准误的 2 倍以内（数据 `results/9.29/tddb_phase0_box*.csv`）。3–4 V 本底以 TAT 为主（25 °C 占 99.9% 以上），
R1 比总电流低 7 个数量级以上，I-t 从 TAT 本底起步。

**依据**：小盒子单个实现散布大（σ(log₁₀J) = 0.9–1.4），I-t 只能看系综。M = 30 给出 20–35% 相对标准误，
与默认盒子 M = 5 相当；同一标准误下两种盒子总机时相当。小盒子的用处是压低击穿所需空位数（§6.3）。

## ADR-027 生成速率纯函数的实现口径（Phase 1）
**决策**：
- `rates/generation.py` 放式 T1、T2、T4；前驱俘获速率 `single_electron_capture_rate`，复用引擎的
  WKB、费米分布、R2/R4 等原语，输入口径与 `kmc._rates` 处理真实陷阱相同。前驱参数只有 E_t1（能级、
  局域化半径）与 E_rel1（多声子线型）。
- R4 的声子项数由调用方给（大线型参数需要更多项，见 ADR-030）。
- 有效势垒 ≤ 0 时 P_bb 饱和为 1。
- G 的俘获速率作为参数传入，便于以后换双电子机制（T4′）；体积生成率 N_T·G 由调用方乘。

**验证**（`tests/test_generation.py`）：零场极限、ln G 对 E 线性的斜率、P_bb 饱和、R_1e 与引擎探针陷阱
的 R2+R4 对拍（rtol 1e-12）。

**观察**：R_1e 几乎全部来自弹性 R2，量级由 E_t1 决定，E_rel1 影响 < 0.1%。E_t1 = 1.15 eV 时由阴极侧
1–2 nm 主导；2.2 eV 时改由阳极侧主导、⟨R_1e⟩ 高约 5×10⁴ 倍。

**后续状态**：T12 写法与 T3 **superseded by ADR-030**；"R_1e 只含电极项" **superseded by ADR-039**。

## ADR-028 前驱参数与 p₀ 初值（Phase 1）
**决策**：`precursor_ionization_energy_eV: 1.15`（与 O 空位预设相同）、`dipole_moment_eA: 7.1`
（按 3 V / 25 °C 下 t_BD ≈ 100 s 从 t_BD ≈ N_BD/(N_T·A·∫R_1e dz·P_bb) 反推，零空间电荷外加场）。

**后果**：有效势垒对电压的斜率 (E_A − E_s)/V_s 只由 E_A 决定，与 p₀ 无关；E_A = 4 eV 时为 1.18 eV/V，
25 °C 下 P_bb 每伏变约 20 个数量级。拿到实验电压加速因子后 E_A 与 p₀ 要一起调。

**后续状态**：E_rel1 的含义 **superseded by ADR-029/030**；计入空间电荷后 t_BD ≈ 100 s 的估算不成立（ADR-034）；
p₀ 改为 1 eÅ（ADR-035）。

## ADR-029 E_rel1 与输运的 Huang-Rhys 因子无关（Phase 1）
**决策**：E_rel1 只用于 TDDB 空位生成（进 R_1e 的多声子线型），输运用材料的 `huang_rhys_S`，两者
互不约束，测试不再断言相等。理由：一个描述断键弛豫，一个描述已有空位俘获/放出电子的弛豫，绑定会让
敏感性分析互相串扰。
**superseded by ADR-030**（含义改写、取值改为 1.0 eV；"与输运 S 无关"保留）。

## ADR-030 删去 E_rel = S·ℏω₀，T3 乘 ½，E_rel1 取 1.0 eV（Phase 1）
**决策**：
1. 删去式 T12（E_rel = S·ℏω₀），E_rel1/ℏω₀ 直接作前驱线型 L(m)（T10）的参数，代码变量改名
   `lineshape_parameter`，逻辑不变。理由：同名 S 会让 E_rel1 被误读成输运 S。
2. T3 改为 p₀ = ½·n·Valence·e·d（只改文档，p₀ 由配置直接给）。
3. E_rel1 是第一次电子俘获导致 O-Zr-O 键断裂、O 空位形成的弛豫能，`zro2_tddb.yaml` 暂取 1.0 eV。

**后果**：p₀ 推算不变；线型参数 25 时 R4 需要 ≥ 100 个声子项（80 项误差 1e-4），生成调用取 100。

## ADR-031 簇级平均场内层求解器（Phase 2）
**决策**：
- `mean_field.solve_mean_field` 求占据不动点 p = F(p)：孤立陷阱用单陷阱条件稳态，强耦合簇按 ADR-022
  枚举 2^k 组态解簇内主方程，簇外分数占据作环境（§6.2 的"簇级平均场"）。分簇与 KMC 共用。
- 迭代变量取 ln p，判据为相对残差 max|ln p̂ − ln p| ≤ 1e-10；Anderson 混合（type II，历史 5 步）；
  200 次未收敛标 `converged=False`，不得交付。支持热启动。`kmc.py` 不改。

**理由**：绝对残差会让占据 ~1e-10 的供给陷阱停在 0、漏掉通路；ln p 比 p 收敛快，logit 在 p→1 时精度不够；
Anderson 比简单阻尼快 3–20 倍。

**验证**：孤立强耦合簇等于主方程精确稳态（rtol 1e-10）。与 KMC 对拍（`results/9.29/tddb_phase2_mf_vs_kmc.csv`）：
TDDB 初始配置（N=10）六个工况系综均值之比 1 ± 5×10⁻⁵（开快陷阱）；密集体系（N=96）开快陷阱且通过验证的
实现上为 1.0003。原先报告的"平均场与 KMC 差 30%"复现不出来：剩下的系统差全部来自 KMC 窗口太短、最慢的
陷阱没平衡，窗口够长时差在统计误差内。

**注意**：密集体系拿 KMC 对拍时要开快陷阱，并看占据偏差最大值与时间尺度分离（只看平均值会误判通过）。

**后续状态**：F 里陷阱间跃迁速率的口径 **superseded by ADR-038**；不动点算法不变。

## ADR-032 TDDB 网格步长按团簇库仑能收敛定为 0.25 nm（Phase 3）
**决策**：`grid` 改为 80/80/80（hx = hy = 0.25 nm、hz = 0.1 nm），替换 ADR-025。

**依据**：0.5–0.9 nm 间距的电荷对库仑能与 nx = 100 相差 ≤ 5% 为判据，nx = 80 为 3.6%、64 为 6.7%；
原 13 格把 0.5–0.6 nm 对算低 30–57%。t = 0 本底在两种网格上系综均值差 ≤ 0.7%，Phase 0/2 结论不变。
单次泊松求解 1.9 → 31 ms。

## ADR-033 TDDB 瞬态驱动的实现口径（Phase 3）
**决策**：
1. **外层循环**（`tddb.run_tddb`）：每步求簇级平均场稳态（热启动）→ 算生成率表 → Gillespie 抽事件与位置 →
   追加空位、增量扩静电耦合。停止条件：空位数上限、应力时间上限（Phase 4 加渗流与限流）。
2. `tddb` 段新增 `precursor_concentration_cm3`（N_T）、`generation_grid`、`max_generated_vacancies`、`stop_time_s`。
3. **内层每步从头重建** `KMCSimulation`（近邻表、截断、分簇），只有静电耦合增量扩展（每个新空位 1 次正向 + 3 次
   伴随泊松求解）。不做增量分簇，因为新空位带电会改变已有对的耦合强度（实测最大变化 580–2000%，会跨阈值），
   截断半径也随 N 变；重建每步仅 0.25 s。
4. 生成网格与泊松网格分开配置（默认 16×16×70）。
5. 新空位出生占据 1，出生带入的电子不计入输运电流；每步记录净空间电荷、平均场收敛与分簇诊断、ΣG。
6. `fit_transient` 按 log t 等间距取样做双对数拟合；CLI `tddb` 子命令。只做单层、内层只用平均场。

**验证**（`tests/test_tddb.py`）：增量耦合与从头计算一致（≤ 1e-13）；G = 0 时 I(t) 逐位等于稳态平均场；
每步分簇与新建 `KMCSimulation` 相同；N_T 翻 10 倍时事件序列逐位相同、时刻缩为 1/10。

**后续状态**：单元生成率的"单元中心点值 × V_cell、中心落进禁区整格记 0"与单元内均匀落点 **superseded by ADR-044**；
生成网格（第 2、4 条的 `generation_grid`）与"N_T 只改时间标尺" **superseded by ADR-052**。

## ADR-034 Phase 3 验证结果：空态空位的正空间电荷经场加速项使生成失控（Phase 3）
**结论**：数值验证通过；**物理验收"I-t 双对数近似直线"不满足**。参考参数（E_A = 4 eV、p₀ = 7.1 eÅ）下 I-t 是
"平台 → 近乎竖直陡升"，几微秒内失控；p₀ = 1 eÅ 推迟到约 100 个空位后同样失控（数据 `results/9.30/`）。

**机制**：
1. 空态缺陷带 +e（施主约定）；生成贴阴极（R_1e 由阴极侧弹性俘获主导），新空位能级高于阴极费米能级，
   电子放回阴极，多数空着。
2. 场灵敏度 p₀·(2+κ)/3 很大：一个 +e 在 1 nm 处的场把那里的 P_bb 抬高约 10⁶ 倍，t = 0 的 ΣG 比零空间电荷高
   5 个数量级。
3. 阴极侧的正电荷层抬高集体场，形成正反馈；换成横向平均场也挡不住。

**谁控制 I-t**：N_T 只改时间标尺；E_A 在 P_bb 未饱和时近似只改时间标尺；p₀·(2+κ)/3 经空间电荷决定形状与
失控早晚。局域场口径下 ΣG 对生成网格不收敛。

**待定的处理**：P_bb 用的场 → ADR-043；E_A/p₀ 与电荷态 → ADR-035。

## ADR-035 进入 Phase 4 前的参数与生成空位电荷态（Phase 4）
**决策**（用户定）：
1. p₀ = 1 eÅ，N_T = 3×10¹⁸ cm⁻³；E_A 配套取 0.95 eV，使 3 V / 8 nm 下有效势垒仍为 0.45 eV。
2. **生成空位出生电荷态 0**（被前驱俘获的电子占据），电子发射后为 +1，即施主约定 `charge_state_Z = +1`；代码不改。
3. k_TH = 1 W/(m·K)；渗流距离 d_c = 0.9 nm（`percolation_distance_nm`）；限流作为第二停止条件。

**后果**：有效势垒对电压斜率降到 0.167 eV/V（γ ≈ 5.2 cm/MV）；时间标尺拉长 13.3 倍；正空间电荷正反馈推迟但仍在。

**后续状态**：k_TH **superseded by ADR-040**；d_c 与限流 **superseded by ADR-047**；N_T 与 E_A **superseded by ADR-052**。

## ADR-036 热反馈、渗流击穿判据与限流的实现口径（Phase 4）
**决策**：
1. `thermal.py`：`heat_release` 在平均场稳态上按事件累加放给晶格的能量（式 T13，能量零点为阴极费米能级，
   电极侧取各自 μ）；`solve_temperature` 复用泊松求解器解 T14（P = −k_TH·∇²T，两电极恒温，规格里的符号已改正）。
2. **温度怎样进速率**：生成率按单元局域温度；内层输运用全局标量 T(t)，取按缺陷放热加权的温度（横向平均温升
   可忽略，放热集中在电流通路上）。输运与热不迭代自洽，第 k 步输运用第 k−1 步的温度。
3. **击穿判据**：全部缺陷按距离 < d_c 连边（xy 最小镜像），同一分量同时贴近两电极即击穿，t_BD 为该记录时刻。
   论文的"25 个空位、间距 ≤ 6 Å"致密团簇只记录、不作判据。
4. **限流**：J ≥ `compliance_current_density_A_cm2` 即停，渗流先检查。`thermal_conductivity_W_mK` 省略即等温。
5. `kmc.py` 只拆分函数供放热复用，结果逐位不变。

**验证**：温度剖面等于解析抛物线；能量守恒（介质 + 电极放热 = U·I_陷阱）在不切分强耦合分量时 ≤ 1.3×10⁻⁹；
渗流判据的周期边界与断链情形。

**观察**：介质放热只占 U·I 约 1%，TAT 电子多半在较高能级隧穿进阳极，能量放在阳极里。

**后续状态**：簇与簇外跃迁的放热记账 **superseded by ADR-038**；击穿判据与限流（第 3、4 条）**superseded by ADR-047**。

## ADR-037 Phase 4 验证结果：生成被限制在阴极侧，渗流击穿与热失控都不出现（Phase 4）
**结论**（参考工况 seed 1–4 各 400 个空位，另跑 3 nm 对照，数据 `results/9.30/phase4/`）：
- 数值验证通过；**物理验收三条都不满足**：
  1. I-t 是"台阶 → 陡升"，不是"幂律段 → 失控上翘"（R² 0.39–0.83）；
  2. 生成空位全部在 z ≤ 1.69 nm，团簇离阳极触发线差 5 nm 以上；
  3. 热反馈可忽略（加权温升 < 2×10⁻⁴ K），开 / 关热反馈事件序列相同。
- **根因一：生成贴阴极**。R_1e 只算电极隧穿，阴极侧 0.5–1.5 nm 是约 1e7 s⁻¹ 平台（费米因子增长抵消隧穿衰减），
  之后每纳米降约 e¹⁷，膜中部低到 1e-9 s⁻¹。
- **根因二：热反馈弱**。介质放热只占 U·I 一小部分，电流 ≤ 2 A/cm²；升温 10 K 约需 J ~ 10⁵ A/cm²。
- **内层求解器问题**：致密空位层上簇级平均场在切开的强耦合分量边界上不守恒粒子数（放热是 U·I 的 13.8 倍）；
  逐陷阱平均场的 R7 用 KMC 的 ΔH = E_b − U_ab − E_a，在平均能级上多减 U_ab，破坏细致平衡，零偏压也有热泵。
  对电流影响 ≤ 5%。

**后续状态**：内层自洽 → ADR-038；前驱电子来源选"近旁已占据陷阱" → ADR-039；重新验收 → ADR-041。

## ADR-038 内层平均场的热力学自洽：平均场能级差与边界跃迁共用（Phase 4）
**决策**（用户定）：
1. 陷阱间跃迁每条只算一次、两端共用（`mean_field.mean_field_rates`），按两端归属分三类：
   - 簇内对：按组态求值，ΔH = E_b − U_ab − E_a，与 KMC 相同；
   - 两端都按平均场处理（孤立–孤立、簇–簇）：MA 因子取平均场能级差 ΔH = E_b(p) − E_a(p)；
   - 簇–孤立对：簇成员取组态能级 e_i(s)、孤立端取 E_j(p)，速率随组态变；孤立端按簇内稳态 π 平均。
2. KMC 事件速率保持精确的 −U_ab，`kmc.py` 不改，漏电流侧结果逐位不变。
3. 式 T13 放热走同一组速率，每端能级取它在自身分布下的值。
4. 簇–簇对不做精确处理（需两簇分布乘积平均，代价过大），零偏压留小环流。

**理由**：平均能级已含对方的平均库仑贡献，再减 U_ab 会双向多减、破坏平均场自身的细致平衡；簇–孤立对若用
与组态无关的速率，零偏压下"电极 → 成员 → 边界 → 邻居"仍有环流。

**验证**：漏电流侧 131 个数组逐位不变；Phase 4 终态上电流连续恢复（放热总和 / U·I = 1.0000），零偏压介质放热
降 2–3 个数量级，电流变化 ≤ 0.1%（一例 2.5%）；能量守恒在切开的分量上也按 rtol 1e-8 成立；ADR-031 的对拍重做，
结论不变（数据 `results/9.30/phase4_fix/`）。

**剩余误差**：簇–簇边界的零偏压环流；引擎原有的电极 WKB 势垒含陷阱自身电荷，让簇成员在零偏压下留 1e-3 量级
的非平衡（漏电流侧约定，未改）。

## ADR-039 前驱从近旁已占据的陷阱俘获电子：R_1e 加陷阱项（Phase 4）
**决策**（用户定）：
- R_1e = Σ_两侧电极 (R2 + R4) + Σ_近旁陷阱 p·R7(陷阱 → 前驱)（式 T4/T5 的"电极/陷阱处"）。
- 陷阱项用引擎陷阱间通道的 MA 形式：p·ν0·exp[−r·(1/r_D,陷阱 + 1/r_D,前驱)]·Θ(E_前驱 − E_陷阱)，
  能量差取平均场能级（同 ADR-038），纯函数 `trap_precursor_capture_rate`。
- 理由：电极项本来就几乎全是弹性 R2，陷阱项取弹性/MA 形式与之一致，且能与引擎探针陷阱直接对拍。

**实测**：陷阱项按源陷阱占据加权，而阴极侧空位层前沿多半空着，终态上只占 ΣG 的 ≤ 1.3%，生成仍贴阴极。

**后续状态**：截断半径与"单元中心求值" **superseded by ADR-042**（份额按 ADR-042 重测）。

## ADR-042 R_1e 的陷阱项改为逐源陷阱积分（Phase 4）
**决策**（用户定）：
1. 事件表 = 单元事件（电极项）+ 源陷阱事件（陷阱项）。每个源陷阱一条事件：
   G_i = N_T·p_i·∫_A R7(i → x)·P_bb(x) d³x，A 为窗口内离全部已有缺陷 ≥ min_separation 的区域。这是单元中心求和
   在单元无限细时的极限，与生成网格无关。抽中时按被积函数在源陷阱周围落点。
2. 原因：陷阱项每 0.083 nm 衰减 e 倍，单元横向 1.25 nm，单元中心要么落进禁区、要么把空隙的值算给整格。
3. **求积**（`tddb.TrapCaptureGeneration`）：以源陷阱为中心的球坐标，径向 0.04 nm、极角 24、方位角 24；在 MA 因子
   与 P_bb 饱和两个折点处切开，分段按对数线性精确积分，可放置区域边界插值求交；径向截断到剩余上界 ≤ 1e-3。
4. `generation_rates` 返回 `GenerationTable(cells, traps)`；删去 `single_electron_capture_rate` 的 `traps` 参数与 ADR-039 的截断半径。

**验证**：孤立源陷阱对自适应积分误差 ≤ 5×10⁻³；致密层上 ΣG_陷阱 对求积参数收敛到 2%；三种生成网格下陷阱项逐位
相同（旧算法到 48 格仍差 −69% ～ +29%）（`results/10.02/adr042/`）。

**结果**：陷阱项算对之后生成仍贴阴极（致密终态新空位 z 中位数 0.55–0.62 nm）；电极项的网格依赖仍在 → ADR-043/044。

**后续状态**：源陷阱积分 **superseded by ADR-052**（陷阱项改为在离散前驱位点上对已占据陷阱直接求和）。

## ADR-043 P_bb 改用 Gaussian 窗口平均的宏观场（Phase 4）
**决策**（用户定）：
1. 式 T2 的 E 取泊松场在 σ 的 Gaussian 窗口上的平均（`PoissonSolver.gaussian_average`，xy 用 FFT，z 只在介质内
   加权并逐点归一化）。R_1e 仍用局域电势与局域场。
2. σ = 0.5 nm（约两个晶格常数），配置项 `tddb.field_averaging_width_nm`，取 0 回到局域场。
3. 不取整盒横向平均，以保留 ≳1 nm 的结构（空位层集体场、团簇尖端聚焦）。

**理由**：Lorentz 关系与连续介质 κ 都要求 E 在约 1 nm 的 Lorentz 球上近似均匀，0.5 nm 处的点电荷场不满足；
E_A、p₀ 也是按宏观场标定的。代价是丢掉"带电空位近旁加速断键"，需要时应作为单独的参数项加回。

**结果**（`results/10.02/adr043/`）：t = 0 网格依赖 ≤ 1.3%；致密状态仍不收敛（单元中心规则所致 → ADR-044）；
致密层 ΣG 比局域场低 17–120 倍；**σ 在致密层上起实际作用**，每变 0.15–0.2 nm ΣG 变约 10 倍，取值依据待定。

## ADR-044 单元电极项改为对单元内可放置区域的积分（Phase 4）
**决策**（用户定）：
1. G_cell = N_T·∫_{cell ∩ A} R_1e,电极(x)·P_bb(x) d³x，A 与陷阱项相同；替代单元中心点值与整格记 0。
2. **求积**（`tddb.ElectrodeCaptureGeneration`）：横向铺间距 ≤ 0.08 nm 的竖直列，列内沿 z（≤ 0.1 nm）对数线性插值积分，
   P_bb 饱和折点切开，禁区球与列的交集按区间精确扣除。生成单元只用来给事件分组，ΣG 与空间分布不随 `generation_grid` 变。
3. R_1e,电极 = Σ R2 + F²·Σ R4/F²（`single_electron_capture_parts`），按前驱能级（0.005 eV）与温度（0.5 K）建插值表，
   完整 WKB 与声子求和只在表节点上做。
4. 落点按积分权重选列与 z 段，再在扣除禁区的区间上按被积函数抽样。N_T 仍只改时间标尺。

**列间距**：≥ 0.1 nm 时列格点与禁区球混叠，致密层 ΣG 跳 ±10%；≤ 0.1 nm 稳定在 ±2%，取 0.08 nm。

**结果**（`results/10.02/adr044/`）：9 个验收状态上 ΣG 及其 z 分布在三种生成网格下逐位相同；求积误差 ≤ 3%；剩余的网格依赖

**后续状态**：单元积分 **superseded by ADR-052**（电极项改为在离散前驱位点上直接求值）。

## ADR-048 生成反应按电荷守恒处理（O_i⁻ 固定电荷），平均场加牛顿法（Phase 4）
**决策**（用户定，ADR-046 方案 1）：
1. `DefectEnsemble` 加逐缺陷固定电荷 `fixed_charge`（q_fix）与位移 `fixed_charge_offset`，缺陷净电荷 q·(Z − n) + q_fix。
   初始缺陷 q_fix = 0；生成空位带 O_i⁻，q_fix = −e（`tddb._INTERSTITIAL_CHARGE`），与空位重合（offset = 0）。新空位出生占据 1，
   连同 O_i⁻ 出生时带 −e，就是前驱俘获的那个电子。O_i⁻ 与空位的距离 d 留作敏感性参数，放置规则待定。
2. 静电：固定电荷与组态无关，`KMCSimulation` 初始化时多解一次泊松方程，作为电势、场与横向平均剖面的背景。与缺陷重合的 q_fix
   属于该缺陷，自作用整项扣除；离开缺陷的 q_fix 是独立的点电荷。R8 的 β 取 Z 加重合的 q_fix/q。生成率的泊松源项把 q_fix 放在各自
   位置；空间电荷记录 Σ[q·(Z − p) + q_fix]。重合时与 ADR-046 what-if（生成空位 Z = 0）等价。
3. 平均场：Anderson 50 次内没收敛就改用牛顿法——有限差分 Jacobian（每列一次 F）+ Broyden 秩一更新 + 回溯线搜索，起点先取热启动的
   p，停住了再从 p̂(0) 重来。判据 1e-10 不变。记录牛顿步数（`newton_steps`，CSV `mf_newton_steps`）。

**平均场不收敛的原因**（what-if 快照 s2_n150，`results/10.09/mf_convergence/`）：
- 不动点映射 F（ln p 上）的 Jacobian 有特征值 1.17，模态落在膜体内分数占据、相距 0.5–1 nm 且按平均场处理的陷阱上（最大强耦合分量
  50 个，被簇大小上限 8 切开）。阻尼迭代的特征值 1 + β(λ − 1) 对任何 β 都大于 1；Anderson 历史 5 / 20 / 50 步、阻尼 0.3、scipy
  newton_krylov 都停在残差 0.15–0.4。
- 与 O_i⁻ 电荷无关：同一组空位取 q_fix = 0 时 Anderson 同样不收敛。ADR-046 主轨迹的空位贴着阴极，没有这种状态。
- 不动点本身良态：G = ln F − ln p 的 Jacobian 最小特征值模 0.15，F 沿迭代方向光滑。牛顿法从 p̂(0) 出发 9 步收敛到 3×10⁻¹⁴；从 Anderson
  游走过的迭代值出发停在 ‖G‖ 的非零局部极小（max|G| = 0.38），所以第二个起点取 p̂(0)。

**验证**：
- q_fix = 0 时漏电流 KMC、平均场、放热与两条 TDDB 短轨迹（O_i⁻ 电荷置 0）共 113 个数组与改动前逐位相同（`results/10.09/qfix0_bitwise/`）。
  ADR-046 参考轨迹最多用 28 次 Anderson 迭代，不进入牛顿法。
- 重合的 q_fix 与 Z → Z + q_fix/q 一致到 1e-12；离开缺陷的 q_fix 等于它单独的泊松解；每次出生介质总电荷正好多一个 −e，其余缺陷处的
  电势、电场变化就是这个 −e 的贡献。
- what-if 里不收敛的状态现在收敛：s2_n150、s2_n200 分别求 F 795、1006 次。seed 1 第 29 个空位（N = 39）牛顿法 27 步收敛，
  J = 6.48 A/cm²；what-if 里这条未收敛记录是 12.6 A/cm²，ADR-047 据此给出的 t = 15.4 s 击穿作废（seed 2 的 41.6 s 落在收敛记录上，不变）。
- `pytest tests/ -v` 308 passed。

**验收**（`examples/zro2_tddb.yaml` 默认工况 3.6 V / 25 °C，seed 1–4，跑到击穿，代码 c3266dc，`results/10.09/accept/`）：
- ΣG 不再自加速：全程 362–442 s⁻¹（t = 0 时 377–407 s⁻¹）。平均场每条记录收敛，都由 Anderson 完成（≤ 10 次），没有进入牛顿法。
- 击穿：第 21–34 个空位、t_BD = 0.040–0.083 s，比实验的约 1000 s 短 4 个数量级。击穿时电流全部是 TAT。
- I-t 仍是台阶状，双对数不成直线：从第一次生成起拟合 n = 0.27 / 0.51 / 0.96 / 0.45，R² = 0.62 / 0.40 / 0.94 / 0.49（seed 1–4），
  四条的几何平均 n = 0.54、R² = 0.63；J 对生成空位数 N：J ∝ N^0.5–1.9，R² = 0.58–0.95。
- 新空位仍在阴极侧：z 中位数 1.1–1.2 nm、最高 1.6–2.4 nm，76–96% 来自电极项。
- 台阶的来源：击穿前只有 21–34 次生成；t = 0 的 J 在四个种子之间差 5 个数量级（5×10⁻⁵ ～ 2.2 A/cm²），离击穿判据只有 0.7–5 个
  数量级；小盒子里一个空位就可能接通一条 TAT 通路（§8.3）。ΣG 恒定时 N ∝ t，I-t 的形状由 J(N) 决定，单条轨迹看不出幂律。
- 待定：t_BD 的标定（N_T 只改时间标尺，t_BD ≈ 1000 s 需要 ΣG 降约 10⁴ 倍）；I-t 斜率要看系综平均（Phase 5）。

## ADR-049 TDDB 配置的缺陷能级取定值（Phase 4）
**决策**（用户定）：`examples/zro2_tddb.yaml` 的缺陷能级由高斯（均值 1.15 eV、σ_E = 0.15 eV）改为定值 1.15 eV，初始缺陷与生成空位

## ADR-050 电极项求积按 z 层分块，建新事件表前释放旧表（Phase 4）
**背景**：缩小 t = 0 电流在种子之间的散布，候选做法之一是加大横向盒子。3.6 V / 25 °C、平均场、seed 1–128、hx = 0.25 nm、其余同
`zro2_tddb.yaml`（`results/10.09/big_box/`）：

| 盒子 | 初始缺陷数 | 中位数 [A/cm²] | 算术平均 ± 标准误 | σ(log₁₀J) |
|---|---|---|---|---|
| 20×20 nm | 10 | 0.165 | 0.62 ± 0.08 | 1.18 |
| 30×30 nm | 22 | 0.32 | 0.48 ± 0.04 | 0.68 |
| 40×40 nm | 38 | 0.34 | 0.41 ± 0.03 | 0.39 |
| 50×50 nm | 60 | 0.38 | 0.44 ± 0.03 | 0.35 |

外层每步的峰值工作集与面积成正比（20 nm 0.83 GB、30 nm 1.80 GB），外推到 50 nm 约 4.8 GB，超过本机空闲内存（约 4.6 GB）。

**原因**（30 nm 逐函数剖析）：
1. 电极项不扣禁区的积分对全部 984 万段一次求出，`_kinked_log_linear_integral` 运行时同时有十几个与段数等长的临时数组，
   工作集 435 → 1487 MB；事件表建完后常驻的只有 313 MB（电极项 268、陷阱项 45）。
2. `run_tddb` 里上一步的事件表到新表赋值时才释放，建新表时两张表同时在内存里，第 1 步峰值比第 0 步高 310 MB。

**决策**（用户定）：
1. `ElectrodeCaptureGeneration`：整段积分逐层求、直接写进权重数组；`_excluded` 只返回被禁区球挡住的段（编号、扣掉的积分、挡住的
   长度比例），同一段的几个区间按出现顺序累加。算式与运算顺序不变。
2. `run_tddb`：抽完生成事件即释放这一步的事件表。

**验证**（`results/10.09/mem_chunk/`）：
- 与改动前逐位相同：20 nm seed 1–4 的 t = 0、`accept/snap_s1_n0025`（35 个缺陷）、30 nm seed 1 的 t = 0 上的单元事件速率、逐段权重、
  源陷阱事件速率，每个状态 60 个单元落点与 20 次抽事件；20 nm seed 1、2 跑到第 10 个空位的轨迹。
- 峰值工作集：20 nm 831 → 245 MB，30 nm 1802 → 472 MB，50 nm 1.20 GB（每步 41 s）。30 nm 每步耗时不变（电极项 13.3 s，改前 13.5–14.1 s）。
- `pytest tests/ -v` 308 passed。

**后续状态**：默认盒子改为 50×50 nm → ADR-051；电极项单元积分随 ADR-052 删去。

## ADR-052 生成改为离散前驱位点：断键一次即用掉，E_A 在前驱之间按高斯分布（Phase 4）
**决策**（用户定，替换 §6.1 模型 C）：
1. t = 0 在可采样窗口里均匀撒 round(N_T·V_窗口) 个前驱位点，每个位点抽 E_A,i = E_A + σ_A·ξ_i（ξ_i 标准正态）；离初始缺陷
   不到 min_separation 的位点删去。
2. 每个位点一条事件 G_i = [Σ_两侧电极 (R2 + R4) + Σ_j p_j·R7(j → i)]·P_bb(E_A,i)，在位点上直接求值，取法同引擎处理真实陷阱；
   P_bb 的场仍取 σ = 0.5 nm 的宏观场（ADR-043）。陷阱项对已占据陷阱直接求和，截断半径让每个前驱截掉的部分 ≤ 10⁻¹² s⁻¹。
3. 抽中的位点原地变成新空位（出生规则同 ADR-048），它与离新空位不到 min_separation 的位点删去。
4. 删去生成单元网格（`tddb.generation_grid`）、电极项单元积分（ADR-044/050）与陷阱项源陷阱积分（ADR-042）；新增配置项
   `activation_energy_sigma_eV`；轨迹记录剩余前驱位点数 `n_precursors`。
5. `zro2_tddb.yaml`：N_T = 10²⁰ cm⁻³（50×50 nm 盒子约 1750 个位点）、E_A = 1.30 eV、σ_A = 0.10 eV。

**依据**（`results/10.11/dispersive/`、`results/10.11/j0_mask/`）：
- 模型 C 不计前驱消耗，ΣG 全程不变（N ∝ t）。ADR-051 击穿时阴极侧 0.5–2 nm 的空位密度 2–3×10¹⁹ cm⁻³，是 N_T 的 6–11 倍。
- §6.1 否决离散前驱的理由（密度上限低于渗流所需的 10²¹–10²² cm⁻³）在 ADR-047 改用电流判据后不再成立：击穿只需 3–5×10¹² cm⁻²。
- t = 0 速率谱粗估（忽略新空位的反馈）：计消耗、N_T = 10²⁰ cm⁻³、σ_A = 0.1 eV 时 N ∝ t^α，α 从 0.5 降到 0.35，N 从 1 到 100 跨
  4.3 个数量级时间；接上 ADR-051 的 J(N)，[1, 1000] s 上 n = 0.31–0.45、R² = 0.69–0.92（不计消耗、只平移 E_A：n = 0.21–0.39、
  R² = 0.50–0.74）。N_T = 3×10¹⁸ cm⁻³ 计消耗时盒内只有约 52 个前驱，到不了击穿。
- 剩下的弯曲来自 J₀：单个空位的电流在 z ≈ 1.25–1.55 nm 最大（E_D = 1.15 eV：1.4 nm 处 0.27 A/cm²，1.1 nm 处 0.012 A/cm²），生成在
  1.1 nm 最快；ADR-051 轨迹里 41% 的新空位在 z < 1.1 nm、每个让 J 增加 0–0.1%，J₀ 由 2–4 个落在这一深度范围内的初始缺陷承载。

**验证**（`results/10.11/discrete/verify.log`）：
- 电极项与引擎在位点放前驱参数探针时的两侧 R2 + R4 相差 ≤ 6×10⁻¹⁴（ADR-044 的插值表为 2×10⁻³）；陷阱项与对全部已占据陷阱的
  直接求和相差 ≤ 2×10⁻¹⁰。
- 默认工况 seed 1 的 t = 0：1747 个位点（3 个落在初始缺陷的禁区里），E_A = 1.302 ± 0.097 eV；ΣG = 10.4 s⁻¹，其中电极项占 99.998%，
  z = 0.5–1.5 nm 的位点占 99%；生成率一步 2.1 s（ADR-050 实测 30 nm 盒子的电极项单元积分一步 13.3 s）。
