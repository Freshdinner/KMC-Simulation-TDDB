# ZrO₂/Al₂O₃/ZrO₂ 叠层改造 — 术语表

> 由 `/grill-with-docs` 会话逐轮扩充，统一叠层改造的用词（ubiquitous
> language）。决策记录见 [adr/zaz-stack-decisions.md](adr/zaz-stack-decisions.md)。

- **Stack（叠层）**：沿 z 方向由有序介质层组成的介质区，本项目具体为
  ZrO₂/Al₂O₃/ZrO₂。
- **Layer（层）**：叠层中一段连续同材料区域，有独立 `layer_id`、材料引用、
  厚度 t_ℓ、缺陷配置引用。两层 ZrO₂ 共享材料参数但各有独立 `layer_id`
  （以便分别设缺陷）。
- **Interface（内部界面）**：相邻两层的交界面（z₁、z₂）。携带导带带阶
  ΔE_C，以及可选的固定面电荷 σ 与界面缺陷。区别于电极接触。
- **Contact（电极接触）**：阴极/阳极与最外层介质的接触，携带接触势垒
  （显式指定，或由 Φ_m − χ 推算）。
- **Band offset / ΔE_C（导带带阶）**：相邻层导带基准之差；默认由电子
  亲和能对齐 `χ_j − χ_{j+1}` 给出（ADR-004）。
- **Material（材料）**：一组介质物性参数（κ、ε_opt、Eg、χ、
  m_cb/m_vb/m_di、ℏω、S、ν0），由层按引用取用。
- **Species（缺陷物种）**：一类缺陷的参数集合（能级参考、m_di、Z 等）。
  当前单物种，接口预留多物种（不同 m_di / 电荷态）。
- **Bulk defect（体缺陷）**：按层配置、以体浓度 n_D（cm⁻³）生成的缺陷，
  数量 = n_D × 层体积（按层一致取整）。v1 只在两层 ZrO₂ 内生成，Al₂O₃
  体内为空（ADR-005）。
- **Interface defect（界面缺陷）**：位于内部界面（z₁/z₂）平面上的缺陷，以
  面密度 Nₛ（cm⁻²）配置、数量 = Nₛ × A，与体缺陷预算分开计。独立物种，
  能级相对 ZrO₂ 侧局部导带底，物性默认取 ZrO₂ 值（ADR-008）。
- **Nₛ（界面缺陷面密度）**：v1 占位 1×10¹² cm⁻²，待标定。
- **Empty layer（空层）**：体内缺陷数为 0 的层（如 v1 的 Al₂O₃）。材料势垒
  仍参与跨层输运；`generate_defects` 须允许空集合（ADR-005）。
- **Blocking layer（阻挡层）**：导带基准高于两侧的中间层（Al₂O₃），对导带
  电子与陷阱间隧穿都构成额外势垒。
- **P_A（PF 收集概率）**：与收集电极之间隔着阻挡层的陷阱，PF 发射的电子穿过
  阻挡层被收集的概率 = 阻挡层**带偏压**导带剖面上的 WKB 透射率 + 热跃因子，
  封顶 1（0≤P_A≤1）；同侧陷阱立即收集 P_A=1。势垒 V(x)=ΔE_C−q·F_Al·x（梯形/
  三角），入射能量取热化到阻挡层入口处势阱侧局部导带底（ADR-017 §1），在零空间
  电荷的带偏压能带上算、与 KMC 组态无关（与 R1 同口径）。进事件表的是
  R8_eff = P_A·R8，挡回原陷阱是空事件（ADR-021 F03 覆盖 ADR-009 的矩形示例）。
  收集方向随驱动电势 U+V_bi 定；非正向工况标"未通过验证"。
- **Null event（空事件）**：执行后系统状态不变的 KMC 事件，等价于不列入
  事件表；PF 被挡回原陷阱即属此类。
- **G_ab（路径重叠因子）**：陷阱间跃迁的几何衰减因子，沿路径按所在材料
  分段积分 `exp[−∫(α_a+α_b)ds]`；同质时退回 `exp[−r_ab(1/r_D,a+1/r_D,b)]`
  （ADR-010）。
- **α_i(s)（局域衰减常数）**：陷阱 i 的波函数在位置 s 处材料中的衰减常数
  `√(2·m_di(s)·[B_ℓ(s) − E_i]₊)/ℏ`，即局域化半径的倒数在异质材料中的推广。
- **Interface-aligned grid（界面对齐网格）**：均匀 hz 的 z 网格，每个内部
  界面恰好落在节点上；κ 按单元取值，每个单元单一材料（ADR-011）。
- **Conditional-flux estimator（条件通量估计量）**：`_conditional_flux` 的
  Rao-Blackwell 化电流估计，按单陷阱条件稳态占据 p̂=C/(C+E) 求通量。它是**局部
  稳态近似**，在耦合跃迁网络里不自动无偏（review F04 给出 25% 反例），须经独立
  验证方能作可信稳态电流：每个工作点同时算三估计量（条件通量、瞬时通量时间积分、
  阳极/阴极净计数+R1）、核对全局电荷守恒、并用小状态空间主方程稳态解
  （`master_equation.py`）作独立算法基准；未通过验证的结果标"未通过验证"、不交付
  （ADR-021 F04 覆盖 ADR-014 的"自动作为主估计量"）。强耦合簇的成员改用簇内条件
  稳态（见下一条，ADR-022）。
- **Coupled cluster（强耦合簇 / 输运簇）**：跃迁速率 ≥ 1e-3 × 两端电极交换速率
  较小者的陷阱对连成的连通分量（上限 8 个陷阱）。簇内 2^k 个组态直接解主方程稳态，
  簇外占据作为环境；单陷阱条件通量是 k=1 的特例（`clusters.py`、`kmc._trap_flux`，
  ADR-022）。按速率连边、供电流估计用，与 TDDB 里按几何距离连边、供击穿判据用的
  "渗流团簇"不是一回事。
- **Validation status（验证状态）**：单点结果的 `validated` + `validation_notes`。
  硬门槛：正向收集、测量窗口充分、KMC 占据与条件稳态 p̂ 接近、批次间电流一致
  （批次均值法相对标准误 ≤ 0.05）、（阳极事件够多时）净计数交叉校验通过；否则未通过。全器件无缺陷（R1-only）无统计量要验证，直接通过。
- **ΔN_inside / 全局守恒**：测量窗口内器件内电子数变化；满足 (I_C−I_A)·Δt=q·ΔN_inside
  （逐事件记账恒等式，F04），推迟内部截面通量不推迟这一全局守恒检查。
- **by_layer（分层归因）**：把逐缺陷通量按 layer_id / interface_id 分组得到
  的端口电流贡献；区别于 through_plane 截面通量（v1 不做）。
- **r_cut（近邻截断半径）**：R6/R7 事件表只列此半径内的缺陷对；按所有材料
  中最慢的衰减推，判据为被丢弃的总速率上界（ADR-013）。
- **Single-layer degeneracy（单层退化）**：`layers` 只含一个元素、或三层
  参数相同且界面效应关闭时，模型回到单层 ZrO₂——作为回归验收用例
  （方案 §12.2）。
