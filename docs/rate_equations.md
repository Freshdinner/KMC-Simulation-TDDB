# 速率方程规格

## 范围
覆盖全部主要输运机制：电极↔陷阱各类跃迁、陷阱↔陷阱跃迁（缺陷间隧穿）、
陷阱→导带 PF 热发射。公式编号（R1–R8）为本项目内部编号，不对应任何外部
文献的公式编号。

## 两种有效质量——不要混用
- `m_cb`、`m_vb`：介质材料导带底/价带顶的"裸"带边有效质量，是由能带结构
  本身给定的。**Weinberg 关系描述的对象不是它们**——它们只是和带隙 Eg
  一起作为输入参数进入这个关系
- `m_di`：隧穿有效质量。**Weinberg 双能带色散关系针对的正是这个量**：它
  描述禁带内虚波矢分支的色散，由 (m_cb, m_vb, Eg) 和电子在禁带中的能量
  位置给出 m_di。这是下面速率公式里实际出现的质量参数（R2、R3、R4/R5 的
  c_MP、r_D，以及 R1 里 P(E_t) 内部的 WKB 计算，全部用 m_di，不是 m_cb）
- 当前阶段 m_di 数值上设为等于 m_cb，但在代码里是两个独立的配置项，不是
  同一个变量的两个名字——这样以后单独调整 m_di（比如真正实现 Weinberg
  色散关系来计算它）不需要改动接口

## 势垒形状约定——一律不含镜像力降低
R1–R8 的所有势垒剖面都**不加镜像力（image-force）势垒降低项 Δφ**：

- 界面处能带保持直线，势垒剖面 = 零场势垒高度 E_B + 泊松方程给出的静电势
  倾斜，不做镜像势圆化
- 势垒高度一律取零场值 E_B，不随电场降低
- 所有 WKB 积分（R1 的 P(E_t)，R2/R3、R4/R5 的 P(E)）都在这个未经圆化的
  直线/分段线性势垒上做
- 因此 **ε_opt 只出现在 R8（PF 发射）里**，其他公式里出现 ε_opt 都是实现
  错误（PF 的 β 项是场致势垒降低，与镜像力势垒降低不是一回事，不受此约定
  影响）

## 尝试频率 ν0
- 可配置参数，**默认 1×10¹³ s⁻¹**
- R6/R7 的前置因子 ν0 与 R8 里的 ν 是**同一个配置项**，不要在代码里写死
  成字面量，也不要各自定义一份

## 机制与统计口径对照

| 编号 | 机制 | 归入统计口径 |
|---|---|---|
| R1（能量阈值以下） | 电极↔电极 直接/FN 隧穿 | 直接/FN隧穿 |
| R1（能量阈值以上） | 电极↔电极 热激发越过势垒 | 热电子发射 |
| R2 | 电极→陷阱 弹性俘获 | TAT |
| R3 | 陷阱→电极 弹性逃逸 | TAT |
| R4 | 电极→陷阱 非弹性（多声子）俘获 | TAT |
| R5 | 陷阱→电极 非弹性（多声子）逃逸 | TAT |
| R6 | 陷阱→陷阱 弹性跃迁 | TAT |
| R7 | 陷阱→陷阱 非弹性跃迁（MA 模型） | TAT |
| R8 | 陷阱→导带 PF 热发射 | PF发射 |

统计按"电子抵达收集电极（或进入导带后被收集）的最后一步事件类型"归类。
R2/R4/R6/R7 作为陷阱间转移的中间步骤时，不直接计入某机制的电流贡献，但
体现在"按缺陷位置分解"的统计里。

## R1 —— 电极↔电极（直接隧穿 / FN 隧穿 / 热电子发射，统一处理）

```
R1 = [A·m_e·k_BT / (2π²ℏ³)] · ∫[0,∞] P(E_t) · ln{
       (1+exp(-E_t/k_BT)) / (1+exp(-(E_t+eU)/k_BT))
     } dE_t
```

- A：电极面积；m_e：自由电子质量（电极侧，即发射极电子质量）；P(E_t)：
  横向能量 E_t 电子的 WKB 透射系数，用 m_di（隧穿有效质量）计算，取决于
  当前势垒剖面（来自泊松方程解）。前置因子里的 m_e 与 P(E_t) 里的 m_di
  是两个不同的物理量，各自出现在各自的位置，不存在谁替代谁的问题
- **能量零点与积分限**：全局能量零点取**负极费米能级**，正极费米能级位于
  -eU；积分变量 E_t 是电子的横向能量，不能为负，故积分下限就是 0。供给
  函数括号里两个指数**同号**
- **方向**：只计负极→正极，正极→负极的直接隧穿忽略
- **统计分解**：以势垒沿隧穿路径的最高点能量 E_barrier,max 为阈值，
  E_t < E_barrier,max 部分计入"直接/FN隧穿"，E_t ≥ E_barrier,max 部分计入
  "热电子发射"
- **实现注意**：R1 不经过任何缺陷，走的是理想平面势垒图像（与下面的
  Richardson-Schottky 对照式同口径），因此势垒剖面取零空间电荷的外加偏压解
  E_C(z) = E_B - e·(U+V_bi)·z/Lz，**按公式求值一次**，不随 KMC 组态重算。
  势垒顶因此恰为 E_B，阈值切分与对照式的 φ_B 严格同口径。电流 I_R1 = q·R1
  在统计末尾直接加到总电流上

### 独立验证：热电子发射子部分 vs. Richardson-Schottky 公式

R1 按上面阈值切分出的"热电子发射"部分算出来后，需要和下面这个独立解析
公式做对比，作为该部分实现是否正确的检验：

```
J_TE = A*·T² · [ exp(-q·φ_B/(k_BT)) - exp(-q·(φ_B+U)/(k_BT)) ]
     = A*·T² · exp(-q·φ_B/(k_BT)) · [ 1 - exp(-qU/(k_BT)) ]
```

- A*：有效理查森常数，A* = 4π·m_cb·q·k_B²/h³（确定使用静态有效质量
  m_cb，不是隧穿相关的 m_di）
- φ_B：零场势垒高度，即 E_B（负极参考）。两项分别是负极侧势垒 φ_B 与正极侧
  势垒 φ_B+U：偏压升高时正极侧那项迅速趋零，整体收敛到
  A*·T²·exp(-q·φ_B/(k_BT))、不随偏压发散，与 electrode_tunneling.py 实现的有界
  双向热发射自洽。旧写法 `[exp(qU/k_BT)-1]` 配负极参考 φ_B 自相矛盾、随偏压
  发散，是规格文档的笔误（错在文档不在实现，见 ADR-002），已订正为此有界形式
- 不考虑镜像力势垒降低（Δφ），按理想零场势垒处理——这与 KMC 侧的口径
  一致（见上文的势垒形状约定），两边用的是同一个势垒模型，所以不存在
  "解析式没算镜像力、KMC 算了"这种系统性偏差
- **适用范围**：这是理想平面势垒近似，没有考虑陷阱的存在。R1 侧既然也在
  外加偏压的理想梯形势垒上求值（见上文"实现注意"），两边就是同一个势垒模型
  且都与缺陷无关，"陷阱造成的场畸变"这个偏差来源不存在，"偏差随缺陷浓度趋于
  零而收敛到零"这条判据**按构造严格满足**——实测三个浓度下热发射电流密度逐位
  相同。剩余偏差只有能量积分的离散误差（实测 <1%）与规格指定的前置因子质量差
- **判据落地成什么**：因为势垒模型与偏压依赖两边完全相同，只剩前置因子的质量
  选择不同（R1 用发射极自由电子质量 m_e，A* 用 m_cb），所以判据取
  **两者之比恒等于 m_e/m_cb，且不随温度、偏压、缺陷浓度漂移**——这比一个模糊的
  "量级差不多"更适合写成测试

## R2 —— 电极→陷阱 弹性俘获

```
R2 = [8·E1^1.5 / (3ℏ√ED)] · (m_e/m_di)^2.5 · f_C(E) · P(E)
```

f_C(E)：电极 C 中费米分布，在陷阱能级 E 处取值（E 随外加偏压和陷阱位置
变化）；E1：电极中电子总能量。

## R3 —— 陷阱→电极 弹性逃逸

与 R2 是同一隧穿过程的反方向，占据因子互补：

```
R3 = [8·E1^1.5 / (3ℏ√ED)] · (m_e/m_di)^2.5 · [1-f_C(E)] · P(E)
```

R2 用电极侧"有电子可用"的概率 f_C(E)，R3 用电极侧"有空位可接收"的概率
[1-f_C(E)]，其余因子相同——这是弹性隧穿满足细致平衡的自然结果，不是
独立拟合出的公式，实现时可作为 R2/R3 共享同一 P(E) 计算的依据。

## R4 —— 电极→陷阱 非弹性（多声子）俘获 / R5 —— 陷阱→电极 非弹性逃逸

```
R4 = ∫[E,∞] N_C(E')·f_C(E')·P(E')·c_MP(E') dE'
R5 = ∫[E,∞] N_C(E')·[1-f_C(E')]·P(E')·e_MP(E') dE'

c_MP(E') = [(4π)²·r_D³·e²·ℏ·F²] / [Eg·2·m_di] · Σ[p=0,∞] δ(E'-E_p)·L_p
e_MP(E') = exp[-(E'-E)/k_BT] · c_MP(E')
```

N_C：电极 C 中态密度；L_p：p 声子跃迁概率；E_p = E + p·ℏω。

**可用于验证的物理约束**：R5 与 R4 之间是细致平衡关系——零偏压热平衡下
两者必须满足这个比例，可直接写成单元测试，比单看"能不能跑"更容易发现
系数错误。

## R6 —— 陷阱→陷阱 弹性跃迁

```
R6(a→b) = ν0 · exp[ -r_ab/r_{D,a} - r_ab/r_{D,b} ]
```

- ν0：尝试频率，可配置，默认 1×10¹³ s⁻¹（与 R7、R8 共用同一配置项，
  见上文"尝试频率 ν0"小节）
- r_{D,a} = ℏ/√(2·m_di·E_{D,a})，r_{D,b} 同理，按各自缺陷的能级计算
  （能级若来自高斯分布，不同缺陷的 r_D 会不同）
- r_ab = √[(x_b-x_a)² + (y_b-y_a)² + (z_b-z_a)²]，两缺陷三维欧氏距离
- 公式允许两个缺陷有不同的局域化半径，为后续引入不同种类缺陷（比如不同
  m_di 或不同物理特性）预留了空间，不需要改公式结构

**叠层推广——分段衰减几何因子（ADR-010）**：异质叠层里波函数沿路径按所在层
材料衰减，几何因子推广为 `G_ab = exp[−∫_γab (α_a+α_b) ds]`，
`α_i(s) = √(2·m_di(s)·[B_ℓ(s) − (B_ℓ(i) − E_D,i)]₊)/ℏ`——`m_di(s)`、`B_ℓ(s)`
取**路径所在层**的材料值（路径传播质量，见 review F08，与进 r_D / R2/R3 前置
因子的物种质量区分）。R6 = ν_ab·G_ab，ν_ab = √(ν_a·ν_b)。**单一材料叠层里
α_i 为常数，逐位退回上面的闭式 `exp[−r_ab(1/r_D,a+1/r_D,b)]`**（含单层与三层
同材料的退化用例）；实现按材料种数选闭式或分段式（`rates/trap_hopping.py::
segmented_overlap_factor`、`kmc.py`）。

**实现注意——只列近邻对**：几何因子的 e 折长度很短（同质材料下 r_D/2，参考
预设 0.083 nm；叠层里最慢的那段也远小于缺陷平均间距），所以稠密 (N,N) 跃迁
矩阵在双精度下几乎全是零。KMC 事件表只列截断半径内的有序缺陷对
（`defects.neighbor_pairs`）。截断半径按**叠层所有材料里最慢的衰减 α_min**
（每个 (缺陷, 层) 组合的 α 里最小的正值，低隧穿质量能压过高势垒——Al₂O₃ 常比
ZrO₂ 衰减更慢）与判据"**被丢弃的总速率上界 < 机制表最小速率**"推出
（`kmc._hop_cutoff_radius`，ADR-013/F05）：N_out·ν_max·exp(−2·α_min·r_cut) <
零场 R8_min，据此反推容差再求半径，不写死成长度。存在零衰减区（α_min=0）时退回
列全部有序对。这是纯数值截断、不是物理近似：单一材料下实测与稠密矩阵实现给出
逐位相同的电流与机制分解。

## R7 —— 陷阱→陷阱 非弹性跃迁（Miller-Abrahams 模型）

```
R7(a→b) = R6(a→b) × Θ(E_a, E_b)

Θ(E_a, E_b) = exp[-(E_b-E_a)/k_BT]   若 E_b - E_a > 0
Θ(E_a, E_b) = 1                       若 E_b - E_a ≤ 0
```

即在 R6 的几何隧穿因子基础上乘一个能量方向的玻尔兹曼因子：跳到更高能级
要付"热激活"代价，跳到更低或同能级不受能量惩罚。实现时 R7 可以直接复用
R6 的计算结果，再乘一个能量项，不用重复写隧穿部分。

**Θ 里的能量差取完整事件能量差，不是跳跃前组态的单点能级差（见 ADR-021 F02）**：
"E_b" 要取电子离开 a 之后终态陷阱 b 上的能级。当前组态里 E_b 含出发陷阱 a 上
那个电子的库仑贡献，电子跳走后这部分消失，所以事件能量差是

```
ΔH(a→b) = (E_b - E_a) - U_ab,   U_ab = q²·G_ab
```

U_ab 是 a、b 两处电子的库仑互作用能，G_ab 为对称静电格林响应（代码里由静电
耦合矩阵的非对角元给出，对 a↔b 两向取对称化值）。把 Θ 改成 Θ(ΔH)：ΔH>0 付
热激活代价、ΔH≤0 不付。这样正反向速率在各自出发组态求值后满足细致平衡

```
R(a→b, n) / R(b→a, n') = exp[ -(H(n') - H(n)) / k_BT ]
```

其中 n、n' 是跳跃前后的完整组态。**只更换几何重叠因子、不改事件能量差修不好
这一点**；单点能级差 E_b-E_a 只在忽略 a、b 库仑耦合（U_ab→0）时才等于 ΔH。

**叠层里换的正是几何重叠因子、事件能量差照旧（ADR-021 F02 覆盖 ADR-010 的能量
处理）**：Phase 4 把 R6 的几何因子从闭式换成分段衰减 G_ab（见 R6 一节的"叠层
推广"），Θ 里的 ΔH=(E_b−E_a)−U_ab 一字不改——正反向细致平衡测试继续过。ADR-010
原本连能量一起改的写法不采用。

这是经典 Miller-Abrahams (MA) 跃迁模型，比多声子量子模型简单得多，是本
阶段有意选择的简化实现。**项目后续完善阶段可能会替换成更精确的量子模型**，
替换时只需要改 R7 内部实现，不影响其他模块。

**本阶段 R6 与 R7 在 KMC 事件表里合并为一条通道**：E_b ≤ E_a 时 Θ=1，
即 R7 ≡ R6，两条并列会把下坡跃迁速率精确地算成两倍。因此陷阱间跃迁一律
走 R7，R6 仍作为独立纯函数实现并单独测试、供 R7 内部调用。等 R7 换成
量子模型、与 R6 不再是"同一条通道的两种写法"之后，两者才需要分开计入。

## R8 —— 陷阱→导带 PF 热发射

```
R8 = ν · exp(-ED/k_BT) · { (1/β²)·[1+(β-1)·e^β] + 1/2 }

β = √[ Z·e³·F / (π·ε0·ε_opt·k_B²·T²) ]
```

ν：尝试频率，与 R6/R7 共用同一配置项（默认 1×10¹³ s⁻¹）；
Z：陷阱失去电子后留下的电荷；F：局域电场。

- **务必使用 ε_opt，不要用静态 κ**——这是这类模型里最容易出错的地方
- **验证建议**：高场（β ≫ 1）极限下，花括号项 → e^β/β，公式退化到带
  1/β 前置因子的指数型 PF 形式

      R8 ≈ ν·exp[-(ED - Δ)/k_BT] / β,   Δ = √(Z·e³·F/(π·ε0·ε_opt)) = β·k_BT

  Δ 就是场致势垒降低量（注意 √ 号内那一坨本身已经是能量量纲，前面不再乘
  一个 e），相对偏差按 1/β 收敛，可作为极限检验用例。β 随场强单调增大，
  **β 大对应的是高场**，指数型 PF 近似本身也是高场渐近形式——两者一致
- 另一个极限：F → 0 时 β → 0，花括号项 → 1 + β/3 + O(β²)（对 e^β 展开到
  β³ 阶即可验证），R8 退化为无场热发射 ν·exp(-ED/k_BT)，这一条同样适合
  写成测试
- **模型局限**：本机制表里 PF 发射没有反向通道（导带→陷阱俘获未建模），
  零偏压下 R8 = ν·exp(-ED/k_BT) 仍非零，会留下一个极小的伪零偏压电流
  （实测比工作点电流小十几个数量级）

## 已确认（本阶段实现时定下的口径）
- **能量零点 = 负极费米能级**，正极费米能级在 -eU。R2/R3 的 E1（"电极中
  电子总能量"）与 R4/R5 的 N_C 需要的是电子相对**该电极导带底**的能量，
  于是电极材料多一个参数：费米能相对其导带底的高度（配置项
  `fermi_energy_eV`，默认 5.0 eV），电极导带底位于 (该电极费米能级 -
  费米能) 处
- R1 供给函数的两个指数同号，积分下限取 0（横向能量非负），只算负极→正极
- **R1 在外加偏压的理想梯形势垒上按公式求值一次**，不随 KMC 组态重算，电流
  I_R1 = q·R1 在统计末尾加到总电流上。势垒顶因此恒为 E_B，与 RS 对照式同
  口径；R1 的两个分量与缺陷实现、seed、事件数全部无关。详见 R1 一节的
